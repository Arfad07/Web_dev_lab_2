
P1 - Terminal Navigation and Project Setup

Objective:
To learn basic terminal commands and project folder navigation.

Commands:

1. pwd
   Displays the current working directory.

2. ls
   Lists files and folders.

3. mkdir foldername
   Creates a new folder.

4. cd foldername
   Changes the current directory.

5. cd ..
   Moves one directory backward.

6. touch filename
   Creates a new file.

7. ls -la
   Displays all files, including hidden files.

Result:
Successfully learned basic terminal navigation
and project folder creation.
